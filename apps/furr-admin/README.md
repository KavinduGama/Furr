# Furr Admin

The restricted internal operations console. It is separate from the consumer experience and receives only the least-privileged administrative data needed for support, clinic approval, safety operations, and compliance workflows.

## First production slice

1. Administrator sign-in and enforced MFA
2. Professional/clinic application review
3. Audit-log search
4. Support operation queue
5. Privacy/deletion request workflow

No raw pet-health documents are shown by default. Access to any sensitive record must be explicit, justified, and audited.
